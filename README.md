# SeekFactory FEW

LinkedIn-style, video-first buyer web app for SeekFactory (India–China B2B manufacturing marketplace).

**Frontend only** — mock data, no paid infra in this milestone.

## Documentation (read this)

Team rules, architecture, design tokens, auth, taxonomy, and China constraints:

➡️ **[AGENTS.md](./AGENTS.md)** — complete project guide for developers and AI agents

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

| Page | URL |
|---|---|
| Reels home | `/` |
| Join (Buyer / Manufacturer) | `/join` |
| Sign in | `/login` |
| Explore categories | `/explore` |
| Manufacturer home | `/factory` (after manufacturer join) |

## Scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Local demo (Turbopack) |
| `npm run build` | Production build |
| `npm run start` | Serve production build |
| `npm run lint` | ESLint |
